## 2. 重构前的代码问题

原 `Program.cs` 把以下内容全部塞进一个 `internal static class Program`：

1. **四套监听器**挤在 `Main` 里，没有边界：
   - 本地 JSON 帧游戏协议（临时长度前缀 wire，供 `LocalGameClient`/启动器）
   - 游戏登录 TCP（NetSocket 帧 + protobuf `TMessage`）
   - 游戏登录 KCP/UDP
   - 真实客户端的 HTTP/TLS 引导（`/phone/*` SDK 端点），藏在 `HandleAsync → CaptureOpaqueAsync` 里
2. **可变静态状态**：`_gameLoginPort`、`_kcpGameLoginPort`、`_gameLoginLogPath` + 一把锁，散落全局。
3. **日志混乱**：`Console.WriteLine`（ready 行）、`Console.Error.WriteLine`（诊断）、手写 `LogGameLogin`（写文件）三种方式并存。
4. **无组合根/依赖注入**：`SqliteGameRepository`、`GameService` 等全部内联 `new`。
5. **HTTP 引导响应**是一长串 `if/else`（`BuildBootstrapHttpResponse`），与流量嗅探、抓包落盘纠缠在一起。
6. 死代码 `ReadGamePacketAsync`（定义但从未调用）。

## 5. 关键设计决策

### 5.1 Generic Host 生命周期

- 每个监听器实现 `BackgroundService`：在 `StartAsync` 里**同步绑定 socket 并回填 `ServerEndpoints`**，再在 `ExecuteAsync` 里跑 accept/receive 循环。
- `Program.Main` 流程：`ServerOptions.Parse` → `--tls-material-only` 分支照旧 → `ServerHostBuilder.Build` → `await host.StartAsync()`（此时端口已全部绑定）→ 输出 `ready` JSON → `await host.WaitForShutdownAsync()`。
- Ctrl+C 由 Generic Host 的 `ConsoleLifetime` 接管，替代原手写 `Console.CancelKeyPress`。

### 5.2 stdout 契约保护（关键）

- 启动器与集成测试读取 **stdout 第一行** 作为 `ready` JSON。Generic Host 默认会把 `"Application started..."` 打到 stdout，故：
  - `ClearProviders()` 后 `AddConsole(o => o.LogToStandardErrorThreshold = LogLevel.Trace)`，把**所有控制台日志重定向到 stderr**；
  - `ready` JSON 仍用 `Console.WriteLine` + `Flush` 直接输出，字段与顺序与现状完全一致（`ready/port/gameLoginPort/kcpGameLoginPort/region/version/tls/rootCertificate/leafCertificate/leafPem/leafKeyPem/capture`）。

### 5.3 日志路由

| 日志类别 | 目的地 |
| --- | --- |
| `BlueOath.Server.GameLogin`（`game-login[...]` 帧诊断） | `game-login.log` 文件（`GameLoginFileLoggerProvider`，锁内 `File.AppendAllText`） |
| 其余类别（`kcp-game-login`、`capture[...]`、`session[...]` 等） | stderr |
| `ready` JSON / `--tls-material-only` JSON | stdout |

- `GameLoginFileLoggerProvider.CreateLogger` 对非目标类别返回 `NullLogger.Instance`，无需 filter 即可只落盘目标类别；另加一条 `AddFilter<ConsoleLoggerProvider>(Category, LogLevel.None)` 避免文件日志在 stderr 重复打印。

### 5.4 端口共享

`ServerEndpoints` 作为单例，由各监听器在绑定后回填真实端口（`--port=0` 时为系统分配的临时端口），供 `BootstrapHttpResponder` 在 `/gethash`、`/phone/serverlist/`、`/phone/loginrole/` 响应中通告正确的游戏登录端口（未配置时回退 7201）。

### 5.5 TLS

`--tls-auto` 时在组装 Host 时调用 `DevelopmentTlsMaterial.Create(...)` 注册为单例；`FrontDoorTcpListener` 经工厂 `sp.GetService<DevelopmentTlsMaterial>()`（未启用时为 null）可选地把连接升级为 `SslStream`。证书文件名/格式不变（`blueoath-local-root.cer`、`blueoath-local-leaf.pfx/pem/-key.pem`）。
