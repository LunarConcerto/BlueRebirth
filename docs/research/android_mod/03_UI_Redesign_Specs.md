# 03 UI 交互重构规范

本文记录启动器主界面、Mod 管理页、存档操作页的最终交互与视觉规范。实现层为 Android 原生 View（Java 注入 + 启动器资源），XML 仅作为布局参考。

## 1. 设计目标

- 小白能看懂：每个页面只做一件事，操作结果用大号文字/彩色状态卡表达；
- 路径信息集中：主界面不展示长路径，路径与状态集中到对应管理页的白色卡片；
- 防误触：破坏性操作（关闭启动器、一键还原）必须二次确认；
- 横竖屏可用：720x1280 竖屏与 1280x720 横屏均通过验证；
- 视觉克制：高饱和蓝作为主色，卡片大圆角、留白 16dp，文字常规字重，避免“黑粗拥挤”。

## 2. 页面结构

### 2.1 主界面（Home）

从上到下：

1. 状态卡（白底圆角，动态文案）：
   - 不能开始游戏：红/黄色调，提示点“安装资源包”；
   - 正在启动：黄色调，提示稍等；
   - 可以开始游戏了：绿色调，提示点“开始游戏”。
2. 主按钮“开始游戏”（绿色大按钮，高 48dp，18sp 常规字重）；
3. 次按钮“安装资源包”（白底蓝描边，高 42dp，14sp）；
4. 两张并列卡片：
   - Mod 管理：标题、存储/Mod 数量、蓝色大按钮“Mod 管理器”；
   - 存档操作：标题、说明、蓝色大按钮“存档管理”。
5. 底部固定操作区（不随内容滚动）：
   - 第一行：防杀后台设置、关闭启动器（40dp 圆角胶囊）；
   - 第二行：看看倒卖狗的是怎么死的、检查新的倒卖狗死妈小技巧、反馈（40dp，10sp，长句自动换行/缩放）；
   - 版权/免费声明一行小字。

主界面右侧“存档管理”与左侧“Mod 管理器”等高、水平对齐（通过占位弹簧实现）。

### 2.2 Mod 管理页

- 顶部标题“BlueRebirth · Mod 管理器”；
- 白色圆角路径卡片：Mod 存放路径 + 扫描状态（扫描到 N 个/覆盖数/耗时）；
- Mod 卡片列表：每张白色圆角卡（16dp 内边距、16dp 卡片间距），左侧勾选框，右侧标题（15sp 常规）、描述（12sp 灰色）；
- 底部按钮两行：
  - 授权存储、刷新并应用；
  - 一键恢复纯净原版、返回主页。

### 2.3 存档操作页

- 顶部标题“存档操作”；
- 白色圆角路径卡片：存档存放路径 + 说明（导入/导出均为服务端 profiles.db）；
- 中间留白，底部三个大按钮：导入存档、导出存档、返回主页。

## 3. 弹窗与状态机

### 3.1 应用 Mod 须知（一次性）

点击“刷新并应用”先弹说明，确认后才执行。正文五条：

1. 请确保 Mod 文件夹已解压到 /sdcard/BlueRebirth/Mods/ 目录下。
2. 点击下方“开始应用”后，请耐心等待进度条走到 100%。
3. 【第一步】提示应用成功后，必须彻底关闭（划掉）当前启动器。
4. 【第二步】重新打开启动器，点击“开始游戏”，客户端会自动拉取更新。
5. 【第三步】更新完成后，再次点击“刷新并应用”以确保最新状态生效。

按钮：我知道了 / 取消。用 noticeShown 布尔值防抖：同一 Activity 生命周期只弹一次，防止无限重复弹窗。

### 3.2 一键还原流程

1. 点击“一键恢复纯净原版”立即弹确认框（标题“一键恢复纯净原版？”，按钮 取消 / 确认恢复）；
2. 确认后显示进度遮罩，执行还原（关闭 Mod、恢复文件、版本回退、清理状态）；
3. 完成后写入 SharedPreferences 标记 restore_pending，并直接结束启动器进程（不弹清数据提示）；
4. 玩家重开启动器，主界面检测到 restore_pending 后弹出一次性提示：
   “已恢复纯净原版！请去系统设置清空客户端数据，然后再进游戏。”
   按钮：我知道了；
5. 弹窗展示同时写入 restore_done，之后无论重启多少次都不再弹。

### 3.3 其它弹窗

- 关闭启动器：标题“关闭启动器？”，正文“关闭启动器可以解决大部分黑屏/卡顿问题。”，按钮 关闭 / 取消；
- 导入存档完成：引导跳转应用设置清数据；
- 还原完成：同一键跳转清数据（与第 4 步合并为一次性提示）；
- 进度遮罩：标题 + 大号百分比 + 进度条 + 步骤说明，不可取消。

## 5. 实现映射

| 界面 | 实现位置 |
|---|---|
| 主界面 | UiInjector（原生 View 注入并覆盖原 C# 界面）+ res/layout/home_ui.xml（静态骨架） |
| Mod 管理页 | SetupActivity（br_mode=mods，程序化布局） |
| 存档操作页 | SetupActivity（br_mode=saves） |
| 应用须知/还原弹窗 | SetupActivity.showApplyNotice / resetVanilla |
| 还原后主界面提示 | UiInjector.maybeShowRestorePrompt |
| 按钮/卡片 drawable | reference_code/ui_layouts/drawable/*.xml |
| 旧版 XML 管理器布局 | assets/bluerebirth/ui_layout.xml |

## 6. 交互细节与边界

- 长句按钮在窄屏会换行或自动缩放，不允许截断文字；
- 所有可点击控件最小高度 40dp，间距不小于 10dp；
- 主界面底部操作区固定在屏幕底部，不随滚动消失；
- 返回键行为：子页面返回主界面；主界面再按返回退出 App；
- 首次安装会弹系统通知权限，属于 Android 13+ 行为，与业务无关；
- 文字不要用已删除的“停止操”等历史按钮；不要恢复过期入口。
