# 04 实机测试闭环与避坑指南

本文是发布前必须执行的验收清单，基于 Android 14 模拟器（720x1280 竖屏）与多轮真实回归总结。

## 1. 环境准备

- 全新模拟器实例，无 Root，分辨率与真机竖屏接近（720x1280，density 320）；
- 安装 02 启动器 APK，授予“所有文件访问权限”；
- 将 5GB 资源包 .brk 推送到 /sdcard/Download（或让测试者用文件选择器选）；
- 准备测试存档（profiles.db）放在电脑侧；
- 记录设备、系统版本、启动器版本、客户端内容版本。

## 2. 五关验收清单

### 第一关：纯净安装与防呆

| 步骤 | 期望 | 证据 |
|---|---|---|
| 安装启动器并授权 | 主界面正常，状态卡可读，按钮不重叠 | 主界面截图 |
| 导入 5GB .brk | 进度条走完，系统弹“要安装此应用吗”，点安装成功 | 进度截图 + 安装弹窗截图 |
| 重启启动器 | 状态变“可以开始游戏了”，服务端目录含 config/bundle | 主界面截图 + 目录大小 |

注意：安装系统弹窗出现时后台解压可能仍显示 99%，属正常；装完重启启动器即可。

### 第二关：UI 分离与死链

| 步骤 | 期望 |
|---|---|
| 点“看看倒卖狗的是怎么死的” | 打开运行日志页 |
| 点“检查新的倒卖狗死妈小技巧” | 弹出“检查更新/已是最新版本”提示，不下载原版包 |
| 点“存档管理” | 只看到导入/导出/返回，无 Mod 列表 |
| 点“Mod 管理器” | 只看到路径卡片 + Mod 列表 + 授权/刷新/还原/返回 |

### 第三关：Mod 递进加载

1. 只放汉化 Mod → 应用 → 重启启动器 → 进游戏：汉化生效，更新只拉少量差异，无 0.00MB 循环；
2. 放齐汉化 + 语音 + 活动 Mod → 应用 → 重启 → 进游戏：活动章节 7/7 LIVE、语音替换、汉化叠加；
3. 关闭活动 Mod → 应用 → 重启 → 进游戏：不崩溃，汉化保留，活动章节恢复 0/7。

### 第四关：一键还原

1. Mod 页点一键还原，立即出现确认框；
2. 确认后进度完成，启动器进程被结束；
3. 重开启动器，主界面弹出“已恢复纯净原版”提示一次；
4. 点“我知道了”后再重启，确认不再弹；
5. 清空客户端数据，进游戏确认日文原版，且不卡“有可用更新”。

### 第五关：存档导入

1. 存档管理 → 导出当前存档，确认 /sdcard/BlueRebirth/Saves/bo-data/profiles.db 存在；
2. 放入测试 profiles.db；
3. 导入 → 启动器自动重启 → 清空客户端数据；
4. 进游戏，大厅刷新后确认账号/等级变为测试档（若仍旧号，正常退出大厅或进一次基地再返回）。

## 3. 黑屏/无响应处理规则

- 首次启动、热更后首次进游戏容易出现黑屏，多数是模拟器渲染/内存问题；
- 先等待 60–90 秒；仍黑屏则重启模拟器（不要反复 adb 强杀）；
- 最多尝试 3 次；3 次仍失败记录“环境原因失败”并跳过，避免在单点烧时间；
- 若日志里只有 SDK 初始化 NPE、无游戏本体崩溃，优先怀疑模拟器渲染，不要改代码。

## 4. 常见误判

| 误判 | 真相 |
|---|---|
| 导入后大厅仍是旧账号 | 客户端会话/大厅未刷新；正常退出大厅或进基地再返回即可 |
| 一键还原后还有中文 | 需清空客户端数据并重新下载资源；确认是客户端旧缓存 |
| 更新 0.00MB 循环 | 发布版本与 assetmap 首行不一致，或 assetmap 被压缩 |
| 客户端下载失败/404 | 缺少 compressed/config gzip 变体，或 assetmap 指纹与服务器文件不符 |
| 应用后游戏没变化 | assetmap 指纹没更新，客户端认为文件没变 |
| 管理器显示 0 个 Mod | 目录名不是 .mod、mod.json 不在根目录、存储未授权 |

## 5. 取证与日志

- 截图命名：阶段_场景_序号.png（如 A_lobby.png、B_prog.png）；
- 启动器日志：/sdcard/BlueRebirth/Logs/mods.log；
- Android 日志：adb logcat -s BlueRebirthMod:I；
- 热更目录体积：adb shell du -sm /sdcard/Android/data/com.blueoath.server/files；
- 客户端数据体积：adb shell du -sm /sdcard/Android/data/com.zephyrus.clsy.gp；
- 关键日志关键字：content changed、assetmap version patched、apply done、save import marker consumed、restore prompt shown。

## 6. 发布门槛

- 五关全部通过，或失败项被明确标记为环境/客户端副作用且有客户复测确认；
- 最终包 APK 的 sha256 与本次测试安装包一致；
- 不包含测试存档、签名私钥、临时构建产物；
- 教程、最终包内文件、版本号一致。
