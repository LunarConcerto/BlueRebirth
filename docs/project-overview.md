# 项目概述

> 本文档整理自原仓库根目录的 `项目说明.txt`，保留原始描述，供新读者快速了解项目背景。

## 项目背景

该项目是一个 Unity 网游项目，**当前已关服**。本项目目标是对其进行本地离线复原。

## 文件结构

| 目录 | 说明 |
| --- | --- |
| `blueoath/` | 日服客户端 |
| `苍蓝誓约/` | 国服客户端 |

需要注意：**国服和日服存在版本差别**，日服最后运营的时间更长，因此内容和代码量相应的更多。

## 技术背景

- 该项目基于 **Unity IL2CPP** 编译，因此 C# 部分代码已不可读。
- 该项目基于 **Lua 热更**，因此存在大量可读可编辑的近乎明文的 Lua 逻辑代码。
- 已尝试过常见的 Unity Mod 接口（如 MelonLoader、BepInEx），这些模组加载器**均无法正常运行**。

## 项目目的

1. 还原游戏的基本功能，并能够**一键启动**：直接注入修改客户端的服务器 IP 指向，重定向至本地服务器等。
2. 搭建一套 **Mod 接口**，使其能够执行外部代码（Lua 或 C# 任意一种，选择较容易处理的方式），并对游戏内容进行 Mod。最好能够在日服和国服之间通用。
